Produtos Famaplás

Pedestais para piso elevado, componentes avulsos e o piso elevado completo, todos fabricados em polipropileno com certificação ABNT. E alças plásticas para embalagens.

Componentes avulsos

Componente

Apoio da placa

O topo do pedestal: reforço completo e rosca dupla para manter as placas niveladas.

Ver produto
Componente

Porca niveladora

Ajuste milimétrico de altura e roscas de travamento que impedem o conjunto de girar.

Ver produto
Componente

Bases

Dois modelos de base, com formato pensado para encaixar até nas extremidades das paredes.

Ver produto
Componente

Prolongador

Para projetos que pedem mais altura, com dentes de travamento que mantêm o piso estável.

Ver produto
Componente

Tubo de acoplamento

A solução para vãos grandes, quando a altura mínima do piso passa de 400 mm.

Componente

Porca base

O pedestal mais baixo possível: só duas peças, para projetos com pouca fiação sob o piso.

Guia rápido

Qual composição para qual altura?

Altura do pisoComposiçãoQuando usar
Regulagem mínimaApoio da placa + porca basePouca fiação sob o piso
Até 150 mm de altura acabadaApoio da placa + porca niveladora + Base 02 (estrela)Montagem padrão
Acima de 150 mmMontagem padrão + prolongadorGanho de altura com travamento
A partir de 400 mmApoio da placa + porca niveladora + Base 03 + tubo de acoplamentoVãos grandes para dutos e cabos

Referência geral. Cada projeto é confirmado pela equipe técnica da Famaplás antes do orçamento.
